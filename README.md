# Easypage

เขียนข้อความแบบ Markdown → แชร์เป็นลิงก์ให้คนอื่นเปิดอ่าน
**ทุกอย่างทำบนเซิร์ฟเวอร์** — ฉบับร่าง รายการ การเผยแพร่ ปิด/เปิด ลบ → เปิดจากเครื่องไหน เบราว์เซอร์ไหน ก็เห็นและแก้ได้เหมือนกัน
ส่วน parse + แสดงผลใช้ชุดเดียวกับ `ai/mdparse` (Parsedown + KaTeX + ปุ่มธีม/ขนาดตัวอักษร + คลิกกล่องโค้ดหรือโค้ดในบรรทัด `...` เพื่อคัดลอก)

## โครงสร้างโฟลเดอร์
```
easypage/
├─ site/        ← ✅ อัปโหลดเฉพาะโฟลเดอร์นี้ขึ้นเซิร์ฟเวอร์ (ทุกอย่างที่เว็บต้องใช้อยู่ในนี้)
├─ README.md    เอกสาร (ไม่ต้องอัปโหลด)
├─ _box/        พื้นที่ส่วนตัวของเจ้าของโปรเจกต์ (ไม่เข้า git, ไม่ต้องอัปโหลด)
└─ .gitignore · .git
```

## วิธีอัปโหลด (deploy)
1. อัปโหลด **เนื้อหาข้างใน `site/`** ไปไว้ในโฟลเดอร์บนเซิร์ฟเวอร์ที่ต้องการ เช่น `tool.9nano.net/easypage/` (ลากไฟล์และโฟลเดอร์ข้างใน `site/` ทั้งหมดไปวาง — ไม่ใช่ตัวโฟลเดอร์ `site` เอง ไม่งั้นลิงก์จะกลายเป็น `/easypage/site/`)
2. ให้โฟลเดอร์นั้น **เขียนได้** โดยผู้ใช้ของเว็บเซิร์ฟเวอร์ (ระบบสร้าง `p/`, `d/`, `trash/` เอง)
3. เสร็จ — เปิด `…/easypage/` ใช้ได้เลย (ไม่ต้องตั้งค่าอะไร; ตั้งค่าเพิ่มได้ที่ `config.php` ดูข้างล่าง)

**อัปทับตอนอัปเดตได้ปลอดภัย:** `site/` ไม่มีข้อมูลจริงและ `config.php` อยู่ข้างใน — ข้อมูล (`p/`, `d/`, `trash/`) และ `config.php` มีเฉพาะบนเซิร์ฟเวอร์ การอัปโหลดทับจึงไม่ลบ/ทับข้อมูลของคุณ
(ถ้าใช้ `git pull` บนเซิร์ฟเวอร์: ให้ชี้เว็บรูทไปที่โฟลเดอร์ `site/` หรือทำ symlink)

**ทดสอบในเครื่อง:** `php -S localhost:8000 -t site` แล้วเปิด http://localhost:8000/

| ไฟล์ (ใน `site/`) | หน้าที่ |
|---|---|
| `manage.php` | **จัดการ** (ต้องใส่ PIN) — รายการหน้าทั้งหมดบนเซิร์ฟเวอร์ ค้นหา · แก้ไข / ดู / ปิด-เปิด / ดาวน์โหลด .md / ลบ |
| `index.php` | ทางเข้าโฟลเดอร์ (`…/easypage/`) — ส่งต่อไป `manage.php` |
| `edit.php` | **เขียน** (ต้องใส่ PIN) — textarea + preview สด, บันทึกฉบับร่างขึ้นเซิร์ฟเวอร์อัตโนมัติ, เผยแพร่, วันหมดอายุ, อัปโหลด .md |
| `view.php?=xxxxx` | **อ่าน** (เปิดสาธารณะ ไม่ใช้ PIN) — แสดงฉบับที่เผยแพร่ (`p/xxxxx.md`) · ปิดอยู่ / หมดอายุ / ไม่พบ / ลิงก์ผิด → หน้าแจ้งสถานะ |
| `pin.php` | ตัวเรียกระบบ PIN กลาง `pin/gate.php` (ดูหัวข้อ PIN) — `index.php` `edit.php` `api.php` `preview.php` เรียกใช้ |
| `api.php` | API ทั้งหมด (ต้องผ่าน PIN) (list / get / save / publish / close / open / rename / delete) |
| `preview.php` | ตัวอย่างสด + ปุ่ม “ดูตัวอย่าง” — POST markdown → ได้หน้าเดียวกับ view.php (ไม่เก็บอะไร) |
| `render.php` | ขั้นตอนแปลง + เทมเพลตหน้า (ใช้ร่วมกันโดย view/preview) — ตรงกับ `mdparse/mdview.php` |
| `parsedown.php` `mdview.css` | **สำเนา**ของ `mdparse/parsedown.php` และ `mdparse/style.css` — `mdview.css` ปรับ padding บนให้กระชับ (ค้นป้าย `[easypage]`) |
| `md.js` | ตัวแปลงสำรองฝั่งเบราว์เซอร์ — ใช้ทำตัวอย่างตอนไม่มี PHP เท่านั้น |
| `store.js` `base.css` | ตัวเรียก API + เครื่องมือ · สไตล์หน้าเขียน-จัดการ (ตาม `_box/STYLE-GUIDE.md`) |
| `config.sample.php` | ตัวอย่างการตั้งค่า (ไม่บังคับ) → คัดลอกเป็น `config.php` |

## ข้อมูลบนเซิร์ฟเวอร์ (ใช้ไฟล์ ไม่ต้องมี DB)
```
d/<รหัส>.md      ฉบับร่าง (ที่กำลังแก้ — บันทึกอัตโนมัติจากหน้าเขียน)
d/<รหัส>.json    created, updated, pubv (ค่า updated ตอนเผยแพร่ล่าสุด), pubAt, expDate, expTime
p/<รหัส>.md      ฉบับที่เผยแพร่ (ผู้อ่านเห็นเฉพาะอันนี้)
p/<รหัส>.exp     วันหมดอายุของฉบับที่เผยแพร่      p/<รหัส>.closed   ปิดอยู่
trash/<รหัส>-<เวลา>/   หน้าที่ลบ — ย้ายมาเก็บ ไม่ได้ลบทิ้ง (กู้คืนด้วยมือ: ย้ายไฟล์กลับ d/ และ p/)
```
- **ฉบับร่าง ≠ ฉบับเผยแพร่:** พิมพ์แล้วบันทึกลง `d/` อัตโนมัติ ผู้อ่านยังเห็นฉบับเดิมจนกว่าจะกด **เผยแพร่** (คัดลอก `d/` → `p/`) · แก้หลังเผยแพร่ = ป้าย “แก้ไขหลังเผยแพร่”
- หน้าเก่าที่มีแต่ `p/<รหัส>.md` ใช้ได้ — ฉบับร่างสร้างตอนแก้ครั้งแรก
- **ย้ายข้อมูลรุ่นเก่า:** หน้าที่เคยเขียนเก็บไว้ในเบราว์เซอร์ (`easypage:v1`) จะถูกย้ายขึ้นเซิร์ฟเวอร์อัตโนมัติครั้งเดียวที่เปิดหน้าจัดการ (ไม่ทับของที่มีบนเซิร์ฟเวอร์ ไม่ลบของเดิมในเครื่อง)
- **กันข้อความหาย:** ระหว่างพิมพ์มีที่พักในเบราว์เซอร์ ถ้าเน็ตหลุด/ปิดแท็บก่อนบันทึกสำเร็จ ครั้งหน้าจะถามกู้คืน
- **แก้ชนกัน:** ถ้าที่อื่นแก้หน้าเดียวกันไปก่อน จะแจ้งและให้เลือก “โหลดฉบับล่าสุด” หรือ “บันทึกทับ” (ตรวจจากเวอร์ชันที่โหลดมา)
- **ปิด:** ผู้เปิดลิงก์เห็น “บทความนี้ปิดการเผยแพร่อยู่” (HTTP 403) · เปิดกลับได้ (เนื้อหาไม่หาย)
- **วันหมดอายุ** (เวลาไทย, ไม่ใส่เวลา = หมดสิ้นวัน 23:59) — ตั้งในหน้าเขียนแล้วกดเผยแพร่ · เลยเวลา → “ลิงก์นี้หมดอายุแล้ว” (HTTP 410) เนื้อหาเก็บไว้ ตั้งวันใหม่แล้วเผยแพร่เพื่อเปิดกลับ · เซิร์ฟเวอร์ตรวจเวลาเอง
- **ดาวน์โหลด .md** ตั้งชื่อไฟล์ตามชื่อเรื่อง (บรรทัดแรก; ไม่มีใช้รหัสหน้า) · **อัปโหลด .md** ในหน้าเขียนโหลดไฟล์เข้าช่องเขียน
- **ลิงก์ย่อ** ปุ่ม “ลิงก์ย่อ” (หน้าเขียนและหน้าจัดการ) คัดลอก `https://9fly.tv/p/<รหัส>` — ระบบย่อลิงก์แยกต่างหากรับรหัส 5 ตัวของเราไปต่อท้าย · หน้าอ่าน (`view.php`) มีปุ่ม “🔗 ลิงก์ย่อ” ต่อจากปุ่ม Dark กดแล้วแสดงลิงก์ตัวใหญ่ + ปุ่มคัดลอก · เปลี่ยนโดเมน/พาธที่ `SHORT_BASE` ใน `site/store.js` และ `EP_SHORT_BASE` ใน `site/render.php` (ให้ตรงกัน)
- **ชื่อลิงก์ (รหัสหน้า)** สุ่ม 5 ตัว `a-z` กับ `1-9` ตัด `0 o i l` ออกกันสับสน หรือ **ตั้งเอง**ด้วยปุ่ม “✎ ตั้งชื่อลิงก์เอง” ในหน้าเขียน — `A-Z a-z 0-9` `-` `_` ยาว 3–30 ตัว (ไม่ขึ้นต้น/ลงท้ายด้วย `-` หรือ `_`, ไม่รองรับภาษาไทย) · เก็บตัวพิมพ์ใหญ่/เล็กตามที่พิมพ์ แต่ **ซ้ำไม่ได้แม้ต่างแค่ตัวพิมพ์** (`Abc` กับ `abc` ถือเป็นชื่อเดียวกัน) และเปิดลิงก์ด้วยตัวพิมพ์อะไรก็เจอ · เปลี่ยนชื่อหน้าที่เผยแพร่แล้วได้ แต่ **ลิงก์เดิมจะเปิดไม่ได้อีก** (ถามยืนยันก่อน) · ลิงก์ย่อต้องรับชื่อที่ยาว/มี `-` ได้ด้วย

## PIN (ระบบเดียวกับ cboard)
หน้าจัดการ/เขียน/API/ตัวอย่างสด ต้องใส่ PIN ก่อน — ใช้ระบบกลางที่ `tool/pin/` (ตั้ง PIN ที่ `pin/config.php` ที่เดียว, ใส่ครั้งเดียวผ่านทุกหน้าในโดเมน, ผิด 5 ครั้งล็อก 30 วินาที) · **`view.php` (ลิงก์ที่แชร์) ยังเปิดอ่านได้ทุกคน**
- โครงสร้างที่คาดไว้: `tool/pin/` อยู่ข้าง `tool/easypage/` — `pin.php` หา `pin/gate.php` แบบสัมพัทธ์ (`../pin`, `../../pin`, `../../../pin`) จึงไม่ผูกกับโดเมน/URL
- ย้ายไปโฮสอื่น: วางโฟลเดอร์ `pin/` ไว้ข้างโฟลเดอร์ easypage (หรือชี้ path เองด้วย `'pin_gate' => '/path/to/pin/gate.php'` ใน `config.php`) — หาไม่เจอ = ล็อกปิด (503) ไม่ปล่อยเปิด
- ปุ่มออกจากระบบอยู่มุมขวาของหัวหน้าจัดการ/เขียน · หน้าจัดการคือ `manage.php`, หน้าเขียนคือ `edit.php` — `index.php` / `index.html` / `edit.html` เหลือไว้เป็นตัวเด้ง (กันลิงก์เก่า)
- ⚠️ ไม่มีเจ้าของหน้า: ผู้ที่รู้ PIN แก้ได้ทุกหน้า · nginx ให้ตั้ง index เป็น `index.php`

## สิทธิ์ (ช่วงนี้ “ทุกคนใช้ได้” — ยังไม่มีระบบสิทธิ์)
ไม่ต้องตั้ง `config.php` ก็ใช้งานได้ · ใครเปิดเว็บได้ก็เห็นรายการทุกหน้า **และ แก้/เผยแพร่/ปิด/ลบ ได้ทุกหน้า** (ไม่มีเจ้าของหน้า — เพื่อให้ทุกเครื่องเห็นเหมือนกัน) ปิดรายการรวมด้วย `'list' => 'off'`

| `publish` ใน config.php | ใครแก้ได้ |
|---|---|
| `open` (**ค่าเริ่มต้น**) | ใครก็ได้ ไม่ต้องล็อกอิน |
| `local` | เฉพาะเครื่องตัวเอง (localhost) |
| `password` | ต้องใส่รหัสผ่าน (`password_hash`, แนะนำ HTTPS) |

ตัวกันที่มี: จำกัดจำนวนครั้งต่อ IP (บันทึก 600/5 นาที, เผยแพร่-ปิด-เปิด-ลบ 60/5 นาที), จำกัดจำนวนหน้ารวม `max_pages` (2000), ข้อความ ≤ 2MB, ต้องมี header `X-Easypage: 1` + Origin ตรง Host (กัน cross-site), แสดงผลแบบ safe mode (ไม่รัน HTML/JS ที่แทรกมาใน markdown), ลบ = ย้ายไป `trash/`
⚠️ ยังไม่มีการกันสแปม/การแก้ทับโดยคนอื่น — เปิดไว้ชั่วคราวจนกว่าจะทำระบบสิทธิ์

## ข้อควรรู้ตอนติดตั้ง
- เซิร์ฟเวอร์ต้องมี PHP
- **nginx:** `.htaccess` ใช้ไม่ได้ ต้องกันเอง เช่น `location ~ ^/easypage/(d|p|trash)/ { deny all; }` (ไม่งั้นเปิด `p/รหัส.md` หรือ `d/รหัส.md` ตรงๆ ข้ามการปิด/หมดอายุ/ฉบับร่างได้)
- `site/config.php`, `site/p/`, `site/d/`, `site/trash/` ไม่เข้า git (ดู `.gitignore`) — เป็นข้อมูล/ค่าตั้งของแต่ละเครื่อง

## หมายเหตุสำหรับคนแก้โค้ด
- `site/manage.php` / `site/edit.php` เรียก `store.js`, `md.js`, `base.css` ด้วย `?v=N` — **แก้ไฟล์เหล่านี้แล้วให้เพิ่มเลข `v` ในทั้งสองหน้า** (ตอนนี้ `v=16`) กัน HTML รุ่นใหม่ไปคู่กับ JS รุ่นเก่าที่ค้างแคช · `.htaccess` ที่ราก (Apache) ตั้ง `no-cache` ให้ไฟล์ html/js/css อีกชั้นหนึ่ง
- ต่างจาก mdview เล็กน้อย: regex แปลง URL เปล่าไม่แตะ `src="..."` และเปิด safe mode
