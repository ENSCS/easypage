# Easypage

เขียนข้อความแบบ Markdown → แชร์เป็นลิงก์ให้คนอื่นเปิดอ่าน
ส่วน parse + แสดงผลใช้ชุดเดียวกับ `ai/mdparse` (Parsedown + KaTeX + ปุ่มธีม/ขนาดตัวอักษร + คลิกกล่องโค้ดเพื่อคัดลอก)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | **จัดการ** — รายการหน้าที่เขียน, ค้นหา, ลบ, เผยแพร่/ดาวน์โหลดต่อรายการ |
| `edit.html` | **เขียน** — textarea + preview สด, บันทึกอัตโนมัติ, สุ่มรหัส 5 ตัว (`a-z` กับ `1-9` ตัด `0 o i l` ออกกันสับสน) ไม่ซ้ำ |
| `view.php?=xxxxx` | **อ่าน** — อ่าน `p/xxxxx.md` แล้วแปลงด้วย Parsedown (ลิงก์เปิดแท็บใหม่) |
| `preview.php` | ตัวอย่างสดของหน้า edit และปุ่ม “ดูตัวอย่าง” — POST markdown → ได้หน้าเดียวกับ view.php (ไม่เก็บอะไรไว้; `?full=1` = มีปุ่มธีม/ขนาดตัวอักษร) |
| `render.php` | ขั้นตอนแปลง + เทมเพลตหน้า (ใช้ร่วมกันโดย view/preview) — ตรงกับ `mdparse/mdview.php` |
| `parsedown.php` `mdview.css` | **สำเนา**ของ `mdparse/parsedown.php` และ `mdparse/style.css` — `mdview.css` ปรับ padding บนให้กระชับ (ค้นป้าย `[easypage]`) ถ้าแก้ต้นฉบับให้คัดลอกมาแล้วทำซ้ำจุดนั้น |
| `md.js` | ตัวแปลงสำรองฝั่งเบราว์เซอร์ — ใช้ทำตัวอย่างตอนไม่มี PHP เท่านั้น |
| `publish.php` | **ปุ่มเผยแพร่** — POST markdown → เขียน `p/รหัส.md` บนเซิร์ฟเวอร์ให้เลย (ดูหัวข้อ “ความปลอดภัยของการเผยแพร่”) |
| `config.sample.php` | ตัวอย่างไฟล์ตั้งรหัสผ่านเผยแพร่ → คัดลอกเป็น `config.php` |
| `store.js` `base.css` | ที่เก็บข้อมูล/เผยแพร่/เครื่องมือ · สไตล์หน้าเขียน-จัดการ (ตาม `_box/STYLE-GUIDE.md`) |
| `p/xxxxx.md` | ไฟล์เผยแพร่ = markdown ดิบ ชื่อไฟล์คือรหัส |

## วิธีทำงาน
1. เขียนที่ `edit.html` → บันทึกใน `localStorage` ของเบราว์เซอร์ผู้เขียนอัตโนมัติ (ชื่อเรื่อง = บรรทัดแรก)
2. กด **ดูตัวอย่าง** เพื่อทดสอบหน้าอ่านจากฉบับร่าง (ยังไม่เผยแพร่)
3. กด **เผยแพร่** → เซิร์ฟเวอร์เขียน `p/รหัส.md` ให้เลย แล้วส่งลิงก์ `view.php?=รหัส` ให้คนอื่นได้ (แก้ไขแล้วกดเผยแพร่อีกครั้งเพื่ออัปเดต)
   - หน้า `index.html` มีปุ่มเผยแพร่ต่อรายการ
   - ทางเลือก: “ดาวน์โหลดไฟล์ (.md)” แล้ววางในโฟลเดอร์ `p/` เอง (ใช้กับเซิร์ฟเวอร์อื่น)
   - มีไฟล์ `.md` อยู่แล้ว: กด “อัปโหลด .md” ในหน้าเขียน (หรือลากไฟล์มาวางที่ช่องเขียน) เพื่อโหลดเข้ามาแก้/เผยแพร่

## ความปลอดภัยของการเผยแพร่ (`publish.php`)
- **ไม่มี `config.php`** → รับเฉพาะคำขอจากเครื่องตัวเอง (localhost, ไม่ผ่าน proxy) — ขึ้นเว็บจริงจะปฏิเสธทุกคำขอ
- **ขึ้นเว็บจริง**: คัดลอก `config.sample.php` เป็น `config.php` ตั้ง `password_hash` (ใช้ HTTPS) → ปุ่มเผยแพร่จะถามรหัสผ่านครั้งแรก (จำไว้เฉพาะแท็บ)
- เขียนได้เฉพาะ `p/<รหัส 5 ตัว a-z0-9>.md` ≤ 2MB, ต้องมี header `X-Easypage: 1` และ Origin ตรง Host (กัน cross-site)
- โฟลเดอร์ `easypage/` และ `p/` ต้องให้ผู้ใช้ของเว็บเซิร์ฟเวอร์เขียนได้
- ยังไม่มีปุ่ม “ยกเลิกเผยแพร่” — ลบไฟล์ใน `p/` เองถ้าต้องการถอนหน้า

หมายเหตุ
- เซิร์ฟเวอร์ต้องมี PHP (ทดสอบ: `php -S localhost:8000` ในโฟลเดอร์นี้)
- ข้อมูลต้นฉบับอยู่ในเบราว์เซอร์ (ล้างข้อมูลเว็บแล้วหาย) — หน้าที่เผยแพร่แล้วมีไฟล์สำรองอยู่ใน `p/` อัปโหลดกลับมาแก้ได้
- คนอื่นเปิด `edit.html` ได้ แต่แก้ได้เฉพาะข้อมูลในเบราว์เซอร์ตัวเอง และเผยแพร่ไม่ได้ถ้าไม่มีรหัสผ่าน
- เหมือน mdview: ไม่ได้เปิด safe mode ของ Parsedown (HTML ดิบในไฟล์ .md ใช้ได้) — เพราะไฟล์ใน `p/` มีแต่ที่เจ้าของวางเอง
- ต่างจาก mdview เล็กน้อย: regex แปลง URL เปล่าไม่แตะ `src="..."` (กันรูปที่ใช้ URL เต็มพัง)
- รหัสที่สุ่มใหม่ไม่มี `0 o i l` — หน้าเก่าที่รหัสมีตัวอักษรเหล่านี้ยังเปิด/แก้/เผยแพร่ได้ (ระบบตรวจรหัสที่มีอยู่แค่ `a-z0-9` 5 ตัว)
- `p/start.md` เป็นตัวอย่าง (`view.php?=start`) ลบได้
