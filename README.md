# Easypage

เขียนข้อความแบบ Markdown → แชร์เป็นลิงก์ให้คนอื่นเปิดอ่าน
ส่วน parse + แสดงผลใช้ชุดเดียวกับ `ai/mdparse` (Parsedown + KaTeX + ปุ่มธีม/ขนาดตัวอักษร + คลิกกล่องโค้ดเพื่อคัดลอก)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | **จัดการ** — รายการหน้าที่เขียน, ค้นหา, ลบ, **ปิด/เปิด**/ดาวน์โหลดต่อรายการ |
| `edit.html` | **เขียน** — textarea + preview สด, บันทึกอัตโนมัติ, สุ่มรหัส 5 ตัว (`a-z` กับ `1-9` ตัด `0 o i l` ออกกันสับสน) ไม่ซ้ำ |
| `view.php?=xxxxx` | **อ่าน** — อ่าน `p/xxxxx.md` แล้วแปลงด้วย Parsedown (ลิงก์เปิดแท็บใหม่) · ถ้าปิดอยู่/ไม่พบ/ลิงก์ผิด จะขึ้นหน้าแจ้งสถานะ |
| `preview.php` | ตัวอย่างสดของหน้า edit และปุ่ม “ดูตัวอย่าง” — POST markdown → ได้หน้าเดียวกับ view.php (ไม่เก็บอะไรไว้; `?full=1` = มีปุ่มธีม/ขนาดตัวอักษร) |
| `render.php` | ขั้นตอนแปลง + เทมเพลตหน้า (ใช้ร่วมกันโดย view/preview) — ตรงกับ `mdparse/mdview.php` |
| `parsedown.php` `mdview.css` | **สำเนา**ของ `mdparse/parsedown.php` และ `mdparse/style.css` — `mdview.css` ปรับ padding บนให้กระชับ (ค้นป้าย `[easypage]`) ถ้าแก้ต้นฉบับให้คัดลอกมาแล้วทำซ้ำจุดนั้น |
| `md.js` | ตัวแปลงสำรองฝั่งเบราว์เซอร์ — ใช้ทำตัวอย่างตอนไม่มี PHP เท่านั้น |
| `publish.php` | **ปุ่มเผยแพร่** — POST markdown → เขียน `p/รหัส.md` บนเซิร์ฟเวอร์ให้เลย (ดูหัวข้อ “ความปลอดภัยของการเผยแพร่”) |
| `config.sample.php` | ตัวอย่างไฟล์ตั้งรหัสผ่านเผยแพร่ → คัดลอกเป็น `config.php` |
| `store.js` `base.css` | ที่เก็บข้อมูล/เผยแพร่/เครื่องมือ · สไตล์หน้าเขียน-จัดการ (ตาม `_box/STYLE-GUIDE.md`) |
| `p/xxxxx.md` | ไฟล์เผยแพร่ = markdown ดิบ ชื่อไฟล์คือรหัส |

## วิธีทำงาน
1. เขียนที่ `edit.html` → บันทึกใน `localStorage` ของเบราว์เซอร์ผู้เขียนอัตโนมัติ (ชื่อเรื่อง = บรรทัดแรก)
2. กด **ดูตัวอย่าง** เพื่อทดสอบหน้าอ่านจากฉบับร่าง (ยังไม่เผยแพร่)
3. กด **เผยแพร่** → เซิร์ฟเวอร์เขียน `p/รหัส.md` ให้เลย แล้วส่งลิงก์ `view.php?=รหัส` ให้คนอื่นได้ (แก้ไขแล้วกดเผยแพร่อีกครั้งเพื่ออัปเดต)
   - เผยแพร่ทำที่หน้าเขียนเท่านั้น (หน้า `index.html` ใช้ดู/ปิด-เปิด/ดาวน์โหลด/ลบ)
   - ทางเลือก: “ดาวน์โหลดไฟล์ (.md)” — ไฟล์ที่ได้ตั้งชื่อตามชื่อเรื่อง (บรรทัดแรกของเนื้อหา; ตัดอักขระที่ตั้งชื่อไฟล์ไม่ได้ออก, ไม่มีชื่อเรื่องใช้รหัสหน้า) ถ้าจะวางเองในโฟลเดอร์ `p/` ต้องเปลี่ยนชื่อเป็น `รหัส.md` · ไฟล์บนเซิร์ฟเวอร์เป็น `p/รหัส.md` เสมอ
   - มีไฟล์ `.md` อยู่แล้ว: กด “อัปโหลด .md” ในหน้าเขียน (หรือลากไฟล์มาวางที่ช่องเขียน) เพื่อโหลดเข้ามาแก้/เผยแพร่

## ปิดบทความ (ไม่ให้อ่าน)
- หน้า `index.html` กด **ปิด** ที่รายการที่เผยแพร่แล้ว → ผู้ที่เปิดลิงก์เห็น “บทความนี้ปิดการเผยแพร่อยู่” (HTTP 403) ไม่เห็นเนื้อหา · กด **เปิดอีกครั้ง** เพื่อเปิดกลับ (เนื้อหาไม่ถูกลบ)
- ทำงานด้วยไฟล์ธง `p/รหัส.closed` (publish.php `?action=close|open`) — ผู้เขียนกด “เผยแพร่” ใหม่ก็เปิดกลับให้เช่นกัน
- สถานะที่หน้าจัดการ/หน้าเขียนแสดงจะตรวจกับเซิร์ฟเวอร์จริงทุกครั้งที่เปิด (`view.php?=รหัส&check=1`)
- `p/.htaccess` ห้ามเปิดไฟล์ใน `p/` ตรงๆ (Apache) เพื่อไม่ให้ข้ามหน้าแจ้งไปอ่าน `p/รหัส.md` ได้ — ถ้าใช้ nginx ต้องตั้งเทียบเท่า (`location /p/ { deny all; }`)

## วันหมดอายุของลิงก์
- หน้าเขียนมีช่อง **วันหมดอายุของลิงก์** (วันที่ + เวลาไม่บังคับ, เวลาประเทศไทย) — ไม่ตั้ง = ไม่หมดอายุ · ไม่ใส่เวลา = หมดสิ้นวันนั้น (23:59:59)
- ตั้งหรือเปลี่ยนแล้วกด **เผยแพร่** เพื่ออัปเดตบนเซิร์ฟเวอร์ (เก็บที่ `p/รหัส.exp`; ส่งค่าว่าง = ลบวันหมดอายุ) — วันที่ต้องเป็นอนาคต (เซิร์ฟเวอร์ตรวจ)
- เลยเวลาแล้ว `view.php` ขึ้นหน้า “ลิงก์นี้หมดอายุแล้ว” (HTTP 410) ไม่แสดงเนื้อหา — เนื้อหายังอยู่ ตั้งวันใหม่แล้วเผยแพร่เพื่อเปิดกลับ
- ตรวจเวลาที่เซิร์ฟเวอร์ทุกครั้งที่เปิดอ่าน (แก้เวลาเครื่องผู้อ่านข้ามไม่ได้) · หน้าจัดการแสดงป้าย “หมดอายุแล้ว” และวันที่หมดอายุ

## การเผยแพร่และสิทธิ์ (`publish.php`)
ตั้งที่ `config.php` (คัดลอกจาก `config.sample.php`; ไม่เข้า git) คีย์ `publish`:

| `publish` | ใครเผยแพร่ได้ |
|---|---|
| `local` (ค่าเริ่มต้นถ้าไม่มี config.php) | เฉพาะเครื่องตัวเอง (localhost) — ขึ้นเว็บจริงจะเผยแพร่ไม่ได้ |
| `open` | **ใครก็ได้ ไม่ต้องล็อกอิน** (ช่วงยังไม่มีระบบ admin) |
| `password` | ต้องใส่รหัสผ่าน (`password_hash`) — ผู้ถือรหัสผ่านจัดการได้ทุกหน้า |

**ใช้งานบนเว็บตอนนี้ (ยังไม่มี admin):** สร้าง `config.php` บนเซิร์ฟเวอร์ ใส่ `'publish' => 'open'`

โหมด `open` มีตัวกันดังนี้:
- **เจ้าของหน้า** — เบราว์เซอร์ที่เผยแพร่ครั้งแรกถือ “กุญแจ” (สุ่ม 128 บิต เก็บใน localStorage) หน้านั้นแก้/ปิด/เปิดได้เฉพาะเครื่องที่ถือกุญแจ (เซิร์ฟเวอร์เก็บแค่ hash ใน `p/รหัส.key`) → คนอื่นเขียนทับหรือปิดหน้าของคุณไม่ได้ · หน้าเก่าที่ยังไม่มีกุญแจ ใครเผยแพร่ครั้งถัดไปคนแรกจะเป็นเจ้าของ
  - **ล้างข้อมูลเว็บ / ลบรายการในหน้าจัดการ = กุญแจหาย** หน้านั้นจะแก้ผ่านเครื่องนี้ไม่ได้อีก (ต้องรอระบบ admin หรือลบ `p/รหัส.key` ที่เซิร์ฟเวอร์เอง)
- **จำกัดการใช้งาน** 30 ครั้ง/5 นาที/IP และจำนวนหน้ารวม `max_pages` (ค่าเริ่มต้น 2000)
- **safe mode** — `view.php` / `preview.php` ไม่รัน HTML/JS ที่แทรกมาใน markdown และกรองลิงก์ `javascript:` (HTML ดิบใน .md จะแสดงเป็นข้อความ)
- ยังไม่มีการกันสแปมเนื้อหา — ใครเปิดเว็บเข้ามาก็เผยแพร่ข้อความได้ จนกว่าจะมีระบบ admin

ทุกโหมด: ต้องมี header `X-Easypage: 1` และ Origin ตรง Host (กัน cross-site) · เขียนได้เฉพาะ `p/<รหัส 5 ตัว a-z0-9>.md` ≤ 2MB · โฟลเดอร์ `easypage/` และ `p/` ต้องให้ผู้ใช้ของเว็บเซิร์ฟเวอร์เขียนได้ · ใช้ HTTPS ถ้าใช้โหมด `password`
- ยังไม่มีปุ่ม “ยกเลิกเผยแพร่/ลบ” บนเซิร์ฟเวอร์ — ลบไฟล์ใน `p/` เองถ้าต้องการถอนหน้า (ใช้ “ปิด” แทนได้)

หมายเหตุ
- เซิร์ฟเวอร์ต้องมี PHP (ทดสอบ: `php -S localhost:8000` ในโฟลเดอร์นี้)
- ข้อมูลต้นฉบับอยู่ในเบราว์เซอร์ (ล้างข้อมูลเว็บแล้วหาย) — หน้าที่เผยแพร่แล้วมีไฟล์สำรองอยู่ใน `p/` อัปโหลดกลับมาแก้ได้
- คนอื่นเปิด `edit.html` ได้ แต่แก้ได้เฉพาะข้อมูลในเบราว์เซอร์ตัวเอง และเผยแพร่ไม่ได้ถ้าไม่มีรหัสผ่าน
- ต่างจาก mdview เล็กน้อย: regex แปลง URL เปล่าไม่แตะ `src="..."` (กันรูปที่ใช้ URL เต็มพัง)
- รหัสที่สุ่มใหม่ไม่มี `0 o i l` — หน้าเก่าที่รหัสมีตัวอักษรเหล่านี้ยังเปิด/แก้/เผยแพร่ได้ (ระบบตรวจรหัสที่มีอยู่แค่ `a-z0-9` 5 ตัว)
- `p/start.md` เป็นตัวอย่าง (`view.php?=start`) ลบได้

## หมายเหตุสำหรับคนแก้โค้ด
- `index.html` / `edit.html` เรียก `store.js`, `md.js`, `base.css` ด้วย `?v=N` — **แก้ไฟล์เหล่านี้แล้วให้เพิ่มเลข `v` ในทั้งสองหน้า** (ตอนนี้ `v=4`) (กัน HTML รุ่นใหม่ไปคู่กับ JS รุ่นเก่าที่ค้างแคช ซึ่งทำให้หน้าจัดการแสดงรายการว่างเปล่า) · `.htaccess` ที่ราก (Apache) ตั้ง `no-cache` ให้ไฟล์ html/js/css อีกชั้นหนึ่ง
